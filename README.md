# 时间 / Time

一个开箱即用的网页时钟，两种形态：**数字时间**与**指针时钟**。零依赖、零构建、无后端，两个静态 HTML 文件即可运行。

在线访问：**<https://www.kuliwu.com/time>**

## 页面

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 时间（数字） | <https://www.kuliwu.com/time> | 超大字号的 `HH:MM:SS`，黑体白底，占满屏幕 |
| 时钟（指针） | <https://www.kuliwu.com/time/clock> | Canvas 绘制的黑盘时钟，秒针平滑扫动 |

两个页面右上角的主题菜单可互相跳转。

## 特性

**时间**
- 数字由 `TimeTravelerPal-Normal-Regular.ttf` 渲染，字体已内嵌为 base64，单文件自包含。
- 每个数字格按最宽字形锁定宽度，秒数跳动时整串数字不会左右抖动；12 小时制的 AM/PM 标签同样定宽。
- 字号按实测字宽/字高自动适配，任意屏幕下约占 86% 宽、50% 高以内，不溢出、不裁字。
- 日期行（`2026年10月14日星期三，第42周`）鼠标移到屏幕下方或触屏点按后淡入，含 ISO 周数。
- 光标悬停底部即显示日期，避免平时干扰观感。

**时钟**
- 表盘为 Canvas 绘制：60 根刻度、5 分钟位置用两位数字标签、1–12 大数字，静态部分预渲染后复用，每帧只画指针。
- 指针是锥形（根部窄、末段满宽带圆头），时针 0.53R、分针 0.80R，长度差足够一眼分辨。
- 秒针以约 25fps 平滑扫动，页面隐藏时 `requestAnimationFrame` 自动暂停，不空转耗电。
- 按 `devicePixelRatio`（上限 3）渲染，高分屏下边缘依然锐利。

**两者共有**
- **服务器时间**：显示的时间取自服务器，不信任访客设备的系统时钟（详见下节）。
- **全屏**：右上角按钮一键全屏，图标随状态切换；不支持全屏的设备（如 iPhone Safari）自动隐藏该按钮。
- **12/24 小时制**：切换结果记入 `localStorage`，下次打开保持。
- 响应式适配 `resize` / `orientationchange`，移动端支持 `dvh` 与安全区。

**屏保（仅时间页）**
- 右上角第一个按钮打开屏保：满屏彩色方块呼吸闪烁，位于最底层且不拦截鼠标事件，与时钟完全解耦。
- 亮度开关切换明暗主题。暗色下为深底 + 霓虹方块 + 白色数字，亮色下为浅底 + 深彩方块 + 深色数字，只改配色，不动布局与字号。
- 方块数量按屏幕面积计算（约每 1.3 万 px² 一块，1080p 约 160 块，手机降至 60 块），窗口缩放防抖 240ms 后重建。
- 关闭时等淡出结束再清空 DOM，避免节点在后台空跑动画。
- 屏保与亮度状态均记入 `localStorage`。

## 时间来源与精度

页面默认走服务器时间，按以下优先级取源，全部失败时回退设备本地时间（离线、`file://` 直接打开也照常显示）：

1. **毫秒级接口**：将脚本顶部的 `API` 填成接口地址（如 `/api/time`），支持返回纯毫秒数，或 `{"t":毫秒}` / `{"timestamp":毫秒}` / `{"now":毫秒}` / `{"ms":毫秒}` / `{"data":{"t":毫秒}}`。
2. **HTTP 响应头 `Date`**：未配 `API` 时对同源地址发 `HEAD` 请求读取 `Date`，nginx / Apache / Node / Python 等静态服务器都会自动带上，无需任何后端。
3. **设备本地时间**：兜底。

`Date` 头只精确到整秒，单次取样只能定到 ±0.5 秒。因此实现上以 150ms 间隔连取 8 次（跨度约 1.05 秒），一旦秒数发生跳变，说明该整秒边界落在相邻两次取样之间，可把相位锁定到约 ±75ms；若 `Date` 被 CDN 缓存住（秒数不跳变），则退回「整秒中点」法。

拿到偏移后，走时用本地单调钟 + 偏移量，并在每 5 分钟、页面重新可见、网络恢复时自动重新校准，避免累积漂移。

## 配置

两个页面顶部的脚本里各有一段配置：

```js
var API='',        /* 毫秒级接口地址，例如 '/api/time'；留空则用响应头 Date */
    TZ=null,       /* null=跟随访客设备时区；填数字如 8 则固定为 UTC+8（北京时间） */
```

`TZ` 用于固定时区。例如服务器与访问者分布在不同时区时，填 `8` 可让所有人看到同一个北京时间。

## 使用

本地打开任意一个 `index.html` 即可（回退到设备时间）；要获得服务器时间，需通过 HTTP 访问：

```bash
# 在仓库根目录起一个静态服务器
python -m http.server 8000
```

然后访问 <http://localhost:8000/>（时间）与 <http://localhost:8000/clock/>（时钟）。

部署：把 `index.html` 和 `clock/index.html` 放到任意静态服务器的对应路径下即可，无需构建。
